## 2 . 调节舵机初始角度

⚠ <span style="color: rgb(255, 76, 65);">**注意：此步骤需要进行舵机角度的校准，按图示操作**。</span>

**校准舵机所需额外零件**

![D1](../media/D1.png)

所需线材：

- 2PIN 公对母杜邦线 颜色随机

![2p200](../media/2p200_1.png)

接线图：

| 舵机 | 舵机控制模块 |
| :--: | :----------: |
| 棕线 |      G       |
| 红线 |      V       |
| 橙线 |      S       |

| 舵机控制模块 | Arduino主控板 |
| :----------: | :-----------: |
|      5V      |      5V       |
|      G       |      GND      |

⚠ <span style="color: rgb(200, 70, 100);">**重要提醒：USB线的一端连接到电脑的USB口，另一端连接到Arduino主控板的USB口。**</span>

![D2](../media/6A85BA.png)

**手指按下这个舵机控制模块上的按钮（90°按钮），舵机就可以转到90°位置。**

![D3](../media/D3.png)

⚠ <span style="color: rgb(200, 70, 100);">**提醒：按照上面图示完成舵机角度的校准后，请将所接线拆除，无需保留。**</span>
